# 最近很多博主在各大网络平台发布用opus5.5“仅用一句提示词”即可制作出精致视频

**经过本人实测之后发现相差甚远，还白耗了很多token，全在踩坑，即使能生成也是质量极差的视频，并不是网上的博主说的“给Claude音乐和类似视频就能制作”那么简单，我希望网上可以少一点虚假宣传，少一点“GitHub又炸了”，“开源圈又爆了”，之类的脑残言论。**
**我有时候也很疑惑，为什么如此没用的视频都能获得一堆收藏，尽管他们只是在故作玄虚的吹牛，我建议各位在收藏视频的时候仔细分辨，亲身体会这个视频是否有用，而不是直接放进收藏夹，不要盲目给这群人增添流量，您的亲身实测比各路博主的吹嘘都更有价值！**

**补充Claude的一个bug**
很多人忽略一个隐藏风险：Claude Code 本地项目模式，会扫描仓库目录内所有文件，哪怕是未提交、被 gitignore 忽略的临时文件、二进制、密钥配置。一旦文件夹混入大量参考文档，不仅 UI 爆炸几万行虚假变更，还会大量消耗 token，甚至读取本地敏感文件。
Git 本身不会这么做，这是 Claude 客户端上层实现带来的设计缺陷。
